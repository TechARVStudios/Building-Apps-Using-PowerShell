Building Apps Using PowerShell

Welcome, this Repository in about learning how to build Apps Using PowerShell Scripts and Compiling them into .exe app executable Application. Here on this Repository you will receive a prebuilt app and PowerShell Script though which you can get idea how to build it. For now here is app built by us named NOTE EDIT and Powershell script is given. Ebook is provided here also for more information and instructions.

Here, there are several files. You can you them to build your own .EXE application with ease. Please read notes as they might be helpful to you.

NOTES-

.ico File- It is your logo or symbol for your application.
.exe File- This is your main application.
.exe.config File- Important File as it contains Configuration of APP.
.ps1 File- Your raw APP file which has to be Compiled into .exe file.
